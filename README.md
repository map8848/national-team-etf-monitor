# 申赎台账

国家队稳市资金监测 · 公开数据测算。

一个纯静态看板：按交易所 ETF 份额日报逐只登记日频净申购，用半年报的实名前十大持有人做校准锚点，并把「哪些是实测、哪些是推测、误差有多大」直接标在界面上。

**本页为公开数据测算，非官方披露。不是投资建议，不输出买卖结论。**

## 为什么不叫「持仓看板」

日频能拿到的只有份额变动。份额变动是全市场一级市场申赎相抵后的**匿名净额**，无法区分中央汇金、做市商、套利盘、机构与个人。把「ETF 份额增加」直接写成「国家队买入」是同类项目里最普遍的口径错误。

所以这里把两行数字分开：

- **全池净申购（匿名净额）**：实测，来自交易所份额日报。
- **疑似入场强度（测算）**：0–100 的启发式打分，命中依据可逐条展开，未接入的依据也列出来。

季度实名持仓不是并列的第二个页面，而是**校准层**：给日频推测提供实名锚点，并把无法闭合的误差摆出来。

## 三层标注

| 层 | 内容 | 界面处理 |
| --- | --- | --- |
| L1 实测 | 交易所份额、收盘价、报告期实名持有人、官方公告 | 硬数据，不加推测标签 |
| L2 推测 | 净申购强度、同步性、连续天数、逆势命中 | 必带「测算」角标，可展开每条依据与分值 |
| L3 校准 | 半年报实名锚点 vs 日频累计 | 冲突标的数、校验偏差、归因缺口直接列出 |

## 核心口径

1. **逐只算金额**：`net_i[t] = (share_i[t] − share_i[t−1]) × price_i[t]`，全池 `Σ net_i ÷ 1e8` 得亿元。不同 ETF 单位净值不同（510300 约 4.135、510500 约 6.67、588080 约 1.298），份额跨标的求和后不能乘一个价格。
2. **收盘价近似净值**：申赎按基金单位净值成交，本页序列里的 `prices` 是二级市场收盘价，折溢价与净值误差未校正。
3. **份额 T+1**：份额当日数据次日披露，序列日期是份额披露对应的行情日，价格对齐到同一交易日。
4. **两个口径不可相加**：ETF 底层仍是股票，个股前十大流通股东口径与 ETF 份额口径存在重复计算。本页不含个股持仓。
5. **主体归一**：定期报告里的股东名称变体极多，`config/entities.json` 用 11 条带 `exclude` 的规则归一到四层主体。纯关键词匹配会把「同瑞汇金3期私募」「…ETF联接基金」误判为国家队，本页一律排除。
6. **份额跳变**：单日大幅变动也可能包含份额折算、合并等非申赎因素，本页未做剔除，只如实呈现并在图表下方标注。

页面里 `N1`–`N10` 的脚注编号都指向「口径与误差」章节，每条都写清了算法与边界。

三方交叉校验：`sse/2026-11-10` 里 510300 的 `TOT_VOL = 4634238.77` 万份 = 46,342,387,700 份；本页序列末值 46,342,387,700 份；东财 `stock/get` 的 `f84 = 46,342,387,712` 份。差异来自浮点取整，不是口径分歧。

标的池取宽基行业 id:0 的全部 22 只，选择标准是「有 2025-12-31 实名前十大持有人锚点可回溯」。588000、512050、159338 等未纳入该库的核心宽基不在池内，因此本页数字**不代表全市场宽基 ETF**。

## 运行

```bash
# 采集公开快照（零依赖，只需 Node 18+）
node scripts/gather.mjs

# 计算派生数据 → data/dashboard.json 与 data/dashboard.js
node scripts/build.mjs

# 或一步到位
npm run refresh

# 冒烟自检：用最小 DOM 执行 app.js，确认九个数据区块都能渲染
npm run smoke
```

然后直接双击 `index.html` 即可打开（用 `<script src>` 加载数据，不依赖本地服务器、不依赖构建、不依赖任何前端框架）。部署到 GitHub Pages 时把 Pages 源设为仓库根目录即可。

日更由 `.github/workflows/daily.yml` 在每个工作日北京时间 16:40 执行采集 + 计算 + 提交。

首次发布用 `scripts/publish.mjs`（零依赖，走 GitHub REST API，不需要 git 出网）：

```bash
GITHUB_TOKEN=<你的 PAT> node scripts/publish.mjs
```

脚本建公开仓库、上传工作区全部文件、开启 Pages、把 Actions 默认权限设为写、触发一次日更，最后回读站点地址。PAT 也可以放在工作区 `.github-pat`（已写进 .gitignore），脚本完成后会删除该文件。classic PAT 需要 `repo` 与 `workflow` 两个 scope；fine-grained PAT 需要对应仓库的 Contents / Workflows / Pages / Actions / Administration 读写权限，且 `POST /user/repos` 不受支持，需先在浏览器建好同名空仓库。用完请立即撤销 token。

用 REST API 创建的初始提交与本地 `git` 历史不同 sha，日更由远端 Actions 自己提交；若之后想在本机继续用 git 推拉，先 `git remote add origin <远端地址>`，再 `git fetch --depth=1 origin && git reset --hard origin/main`。


技术栈说明：原计划 Vite + React + ECharts，实际落地为零依赖静态页 + 自绘 SVG。这个看板只有 205 个交易日 × 22 只标的，不需要框架；去掉构建步骤后页面可以双击打开、Pages 直接托管，图表也能精确按「静音网格、等宽标签、单一强调色」的规范来做，不会带图表库的默认样式。核心架构（纯静态站 + JSON 数据、无后端）不变。

## 已知边界

- 最新实名锚点是 2025-12-31，**归因误差尚未闭合**；22 只里有 12 只出现「锚点份额若不变则隐含占比超过 100%」的冲突，这说明期间必然发生赎回，但匿名日频数据无法判断其中哪一部分属于国家队。需等 2026 年报披露才能回测。
- 深市份额来自数据源的深交所日报，本版未做独立回源校验；上交所标的做了逐日校验。
- 未接入分钟级成交、IOPV、两市成交额与融资余额，因此「尾盘放量」「折溢价」「成交额分位」这几条依据明确标为未接入，不参与打分。
- 事件流只作背景标注，不进入强度打分。
- 数据快照截至 2026-11-10，交易日数 205。

## 与同类项目的差别

GitHub 上同类项目（OrangesHuang/Resonance、kitaki-Ciallo/etf-national-tracker、digger-yu/etf、H-Jett/etf-radar 等）大多把份额变化直接命名为「国家队买入」，且没有一家把「半年报实名前十大持有人 → 回测日频推测」的误差闭环做进界面。本页把口径、未接入项、冲突数与归因缺口全部摊开，并把主体归一字典作为第一天就建的配置文件。

代码不复制任何同类仓库；数据来自 MIT 许可的公开快照与交易所公开日报，已在上方署名。
